The stack

A typed scripting language for LLM agents — with a runtime, an SDK adapter, and a server.

AgentScript OSS compiles a small declarative DSL into an intermediate representation. The runtime executes it. The Vercel adapter wires in any AI SDK provider. The server hosts agents over HTTP, SSE, and WebSocket. Mix or match.

Packages

Three layers. Each one usable on its own.

Pick the layer that matches your integration. The runtime is enough if you bring your own LLM driver. Most users start with the Vercel adapter. Production deployments add the server.

@agentscript/runtime v0.1

The execution core.

Lightweight TypeScript runtime that executes compiled AgentScript OSS IR. Tools, state, guardrails, tracing, and checkpoints. Bring your own LLM driver. 

import { Runtime, ToolRegistry, FnAdapter } from '@agentscript/runtime';

const fn = new FnAdapter();
fn.register('lookup_order', async ({ id }) => ({ status: 'shipped' }));

const tools = new ToolRegistry();
tools.register('fn', fn);

const runtime = new Runtime({ doc, tools, llm: myDriver });
const result = await runtime.run('check ORD-42');
@agentscript/runtime-vercel v0.1

Plug in any AI SDK model.

Vercel AI SDK adapter. Anthropic, OpenAI, Google, or any AI-SDK-compatible provider, with one factory call. Streaming, tool dispatch, and state — handled. 

import { generateText } from 'ai';
import { anthropic } from '@ai-sdk/anthropic';
import { compileSource, createAgent } from '@agentscript/runtime-vercel';

const { output } = compileSource(source);
const agent = createAgent({
  doc: output,
  llm: { model: anthropic('claude-haiku-4-5'), generateText },
  tools,
});
const stream = agent.stream('check ORD-42');
@agentscript/server v0.1

Production HTTP server. Sessions, SSE, WebSocket.

Hono-based server with REST, Server-Sent Events, and WebSocket sessions. In-memory or Postgres storage. Bearer auth, rate limiting, circuit breakers, request timeouts — all configured via environment variables. 

AGENTS_DIR=./agents \
LLM_API_KEY=$ANTHROPIC_API_KEY \
LLM_MODEL=claude-haiku-4-5 \
LLM_BASE_URL=https://api.anthropic.com/v1 \
node packages/server/dist/index.js

Quickstart

From zero to a streaming agent in five steps.

One running example: an order-tracker support agent with a single lookup_order tool. Copy each block top-to-bottom.

Install

Add the three packages and your AI SDK provider of choice.

pnpm add @agentscript/runtime @agentscript/runtime-vercel @agentscript/server \
         ai @ai-sdk/anthropic

Write agents/support.agent

A handful of declarative lines. The compiler turns this into IR the runtime can execute.

agent support {
  description: "Help customers check order status."
  tool lookup_order(order_number: string) -> { status: string }

  on_message(text) {
    let order = extract_order_number(text)
    let result = lookup_order(order_number: order)
    reply("Order " + order + " is " + result.status + ".")
  }
}

Register the tool

Tools are plain TypeScript functions. The server picks them up via the registry.

import { ToolRegistry, FnAdapter } from '@agentscript/runtime';

const fn = new FnAdapter();
fn.register('lookup_order', async ({ order_number }) => ({
  status: order_number === 'ORD-42' ? 'shipped' : 'unknown',
}));

export const tools = new ToolRegistry();
tools.register('fn', fn);

Start the server

The server loads .agent files from AGENTS_DIR, compiles them at boot, and exposes them over REST + SSE + WebSocket.

AGENTS_DIR=./agents \
LLM_API_KEY=$ANTHROPIC_API_KEY \
LLM_MODEL=claude-haiku-4-5 \
LLM_BASE_URL=https://api.anthropic.com/v1 \
node packages/server/dist/index.js

Talk to it

Open a session, then stream a reply over SSE.

SID=$(curl -s -X POST localhost:8080/einstein/ai-agent/v1/agents/support/sessions \
  -H 'Content-Type: application/json' \
  -d '{"userId":"u1"}' | jq -r .sessionId)

curl -N -X POST localhost:8080/einstein/ai-agent/v1/sessions/$SID/messages \
  -H 'Content-Type: application/json' \
  -H 'Accept: text/event-stream' \
  -d '{"message":"check ORD-42"}'

Deploy

Heroku, in five commands.

The server runs on a single web dyno. Optional Postgres for durable sessions. Set three env vars and push. 

# Procfile
web: node packages/server/dist/index.js

heroku create my-agent
heroku buildpacks:set heroku/nodejs
heroku config:set LLM_API_KEY=sk-... \
                  LLM_MODEL=claude-haiku-4-5 \
                  LLM_BASE_URL=https://api.anthropic.com/v1
heroku addons:create heroku-postgresql:essential-0   # optional
git push heroku main
