# Agent bundle

Generated by `agentscript build`. The bundle is a self-contained Node app
hosting the AgentScript server with the `.agent` files under `agents/`.

## Local

```sh
pnpm install
cp .env.example .env  # fill in required env vars
pnpm start
```

## Heroku

```sh
heroku create my-agent
heroku config:set ANTHROPIC_API_KEY=...      # set every var listed in .env.example
git init && git add . && git commit -m "init"
heroku git:remote -a my-agent
git push heroku main
```

The `Procfile` boots `@agentscript/server` against `./agents`. Update the agent
file in place, redeploy, and the agent picks up the new IR on restart.
